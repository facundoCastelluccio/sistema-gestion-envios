Sistema de Gestión de Envíos y Logística
Base de datos relacional creada en MySQL para la gestión integral de envíos, pedidos, clientes y seguimiento de paquetes.

---

Características del Proyecto
- 15 tablas relacionales diseñadas y normalizadas.
- Clientes y Direcciones: Soporte para múltiples tipos de dirección por cliente.
- Pedidos y Detalle: Registro de transacciones con cantidades y precios unitarios.
- Logística y Trazabilidad: Cálculo de distancias en kilómetros, tipos de vehículos por capacidad y control de estados mediante la tabla `seguimientos_envios`.

---

Tecnologías
MySQL, MySQL Workbench, Git/GitHub
